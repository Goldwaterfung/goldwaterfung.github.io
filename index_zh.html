為什麼我要做這個專案？ 隨著 AI Agent 在軟體開發與文字自動化展現強大能力，我觀察到音訊製作領域仍受限於傳統圖形介面與手動操作。在處理龐大的多軌錄音工程時，創作者耗費大量精力在重複的手動路由、Gain Staging 音量平衡與分軌管理。為了探索 Agent 如何自動化音訊工程，我著手從底層構建連結音訊訊號與 Agent CLI 工具的通訊橋樑。
這專案解決的是什麼問題？ 打造原生支援 AI Agent CLI 工作流的音訊工作站架構。系統將底層音訊訊號（峰值分貝、LUFS 響度、頻譜能量分佈與波形特徵）轉譯為確定性 CLI 控制協議與 Tool Calling Schema，讓 Claude Code、Cursor 或 Gemini 等 AI Agent 能檢測音訊遙測數據、組織分軌分組、平衡 Gain Staging、調整聲像 Panning 並透過確定性的命令列指令自動化 DSP 參數。

Measuring Visual Capture in Virtual Reality under Sustained Audiovisual Conflict with Third-Order Ambisonics

探索虛擬實境中視聽衝突下的感官邊界，為空間運算介面提供跨模態感知實證基礎。

為什麼我要做這個研究？ 隨著空間運算與智慧眼鏡的發展，虛擬視聽資訊深度疊加於物理空間。我想透過實證實驗探討當感官輸入相互矛盾時的人類認知邊界：當高保真空間音訊與視覺誘餌提供衝突的空間方位時，大腦是否會壓倒性信任視覺，且該衝突會產生多少可量化的認知代價？
Fung, K. K., Saw, T. W., & Rajapakse, R. P. C. J. (2026). 已獲 IEEE ICVR 2026 接收發表。

三大實驗與學術貢獻：

  1. 實驗範式創新：在 Unity 中設計頭部視線與手部指向解耦追蹤範式，分離感官捕捉效應並記錄即時認知修正軌跡。
  2. 感官捕捉與認知代價實證：證實即便採用 16 聲道三階 Ambisonics 空間音訊，顯著視覺誘餌仍主導初始定位，且跨模態衝突會使認知反應時間增加 1.6 秒。
  3. 空間運算感知基礎：從認知心理學出發，實證單靠空間音訊無法抵銷視覺錯位，為空間運算介面的跨模態視聽協同提供實證數據與設計準則。

CollarAgent - 支援 LangGraph Agent 協作之 Local-First 視覺化研究工作台

整合無限概念畫布、學術文檔引擎與 LangGraph Agent 狀態機，提供非破壞性視覺 Diff 暫存與持久化記憶。

為什麼我要做這個專案？ 在進行文獻回顧與研究假設推導時，研究者常在獨立的白板工具、筆記軟體與 AI 對話視窗之間來回切換，導致思維脈絡碎片化。傳統生成式 AI 亦容易全篇覆蓋草稿而抹除重要論述。為此我打造了一套讓自主 Agent 能在概念圖譜與學術文檔中與研究者安全協作的整合工作台。
這專案解決的是什麼問題？ 構建一套將 LangGraph 狀態機 Agent 與無限概念畫布及支援 LaTeX 數學式與結構化表格的學術文檔引擎深度整合的桌面應用。實現畫布節點與文檔區塊間的雙向狀態同步、非破壞性的視覺化 Diff 提案預覽機制，以及跨工作階段保留專案研究規範的持久化記憶架構。

2. B2B 醫療 3D 模擬與大語言模型臨床診斷培訓系統

角色: User Experience Designer 機構: 醫諾華醫學科技股份有限公司 | 台灣高雄

商業背景與問題發現

醫諾華醫學科技開發結合 LLM 語音對答與 3D 虛擬病人之 B2B 臨床診斷培訓系統。在初期測試中，醫學生在視診環節頻繁出現診斷困惑與誤判，影響臨床培訓效果。

專案目標與學習定位

作為暑期 UX 設計實習生，我的目標是親自系統性走查 50 個虛擬病例，探究導致醫學生誤判的根本原因，並學習將表層體驗問題向上溯源至底層資料架構，向研發團隊提出具體且結構化的建議。

動手走查與根本原因診斷

  • 透過親自走查挑戰既有假設： 團隊初期推測困惑源於 3D 美術精緻度不足。透過結構化使用者走查，我發現核心問題在於功能性缺陷：LLM 語音回覆與化身動作之間的聲影延遲，以及資料庫病徵文字描述與 3D 模型外觀的客觀落差。
  • 系統性資料庫與病例交叉比對： 系統性比對 50 個臨床虛擬病例與資料庫記錄，逐一標註醫療紀錄中提及但 3D 模型上遺漏或標註偏差的細微視覺病徵（如局部紅腫或膚色變化）。
  • 將體驗回饋錨定於客觀事實： 將發現整理為結構化比對矩陣並向工程與醫學主管匯報，引導研發資源優先修復聲影同步與病徵資料庫對齊，而非盲目進行美術外觀升級。

產品影響力與實際成果

將使用者體驗回饋與底層資料庫記錄進行交叉比對，協助團隊精準定位診斷困惑的深層根因，推動研發優先級從表層 3D 重繪轉向基礎資料與同步機制修復。

心得與持續學習反思

學會以可驗證的數據為依歸，由底層理解系統運作架構。 踏入專業醫療領域讓我學會保持謙遜，向領域專家請教、系統性比對底層資料庫架構，並將每一項體驗建議錨定在客觀事實上。

3. 整合 AR 與 RAG 之多模態 AI 即時虛擬校長系統

角色: Systems Integration Engineer 機構: 國立臺南藝術大學

專案背景與目標

本專案研發並部署具備即時語音對答能力的 AR 虛擬校長。在本地 GPU 環境端到端運行多模態推論鏈路（語音識別、大語言模型 RAG 與語音合成）會產生 3 至 5 秒的處理延遲，使現場參觀者誤以為系統無反應。我的職責是將多模態鏈路整合至 Unity，設計即時對話感知緩衝機制以在推論期間提供即時視覺反饋，並在校園公開展演中穩定運行。

跨團隊協作與技術方案

  • 感知延遲掩蔽機制工程： 為化解 3 至 5 秒的運算延遲，我在 Unity 中研發即時對話視覺反饋機制。當檢測到用戶發言結束時，化身立即切換至專注聆聽與運算狀態，向用戶提供明確的運算中視覺確認，直到後端推論完成。
  • 情緒驅動面部聯動與空間視線追蹤： 與 AI 模型團隊合作在回覆封包中嵌入情緒標籤，即時驅動 Unity 面部表情與對嘴 Blendshapes，並整合視線追蹤維持自然眼神接觸。
  • 跨團隊封包時序對齊： 協調前後端音訊與文本封包序列，確保語音播放時唇形精準同步。

產品影響力與實際成果

在校園展演與貴賓接待中公開展示，系統穩定承載多輪即時語音對答。透過響應式感知緩衝化解後端運算延遲，無需額外擴充 GPU 硬體或雲端架構。

心得與持續學習反思

將硬體限制視為深化端到端系統思維的契機。 在有限硬體資源條件下，我體會到透過主動理解整條多模態鏈路的運作原理，並從參觀者的心理感知出發，能以感知延遲掩蔽與跨服務協議對齊化解延遲痛點，打破單一技術邊界。

4. 傳統二胡演奏 Live：AI 動作捕捉與視聽同步系統

角色: Systems Integration Engineer 機構: 國立臺南藝術大學

背景與挑戰

在傳統二胡現場演奏中部署即時虛擬化身面臨顯著的延遲與同步挑戰。快速運弓動作結合即時音訊串流，在排練期間透過 AI 視覺姿態估計模型處理時容易產生畫面抖動與聲影脫節。

跨領域轉譯與工程目標

我的目標是在不損害聲音品質的前提下，在運弓姿態估計與連續音訊串流之間找到最佳緩衝窗口，實現舞台級的穩定展演同步。

排練測試與工程取捨

  • 連結藝術樂句與技術指標： 工程師關注底層封包延遲，而演奏家更看重視覺節奏與起弓時機。透過抱持好奇心觀察排練現場，我將演奏家約 0.8 秒的自然預備運弓動作映射為精確的幀率緩衝閾值。
  • 協同緩衝實作： 將動捕數據與音訊波形並行記錄，確立了 1.5 秒確定性串流緩衝，吸收 AI 推論波動並消除畫面瞬跳，同時保持聲音清晰度。
  • 現場排練與驗證： 在舞台上進行多次完整彩排，驗證虛擬化身的響應節奏與演奏家的肢體表演高度對齊。

產品影響力與實際成果

1.5 秒確定性緩衝在大學音樂廳正式展演中全程保持視線追蹤穩定，並與現場原聲緊密對齊。

心得與持續學習反思

對專業領域保持謙遜，學會跨越學科語彙進行精準轉譯。 與傳統器樂演奏家的深度協作讓我體認到，若技術指標無法服務於人類真實的情感表達就失去意義。與其將工程抽象概念強加於藝術家，我學會傾聽對方的演奏直覺、細心觀察起弓呼吸，並將藝術語彙轉譯為確定性的緩衝閾值。
