Context and Problem Discovery

When preparing a first-author empirical research study for IEEE ICVR 2026, I faced a severe workflow bottleneck. Structuring multi-variable psychoacoustic literature required visual concept mapping, formal mathematical derivations, and continuous prose drafting.

My thinking was fragmented across three disconnected environments: infinite whiteboard tools for spatial diagrams, separate text editors for manuscript drafting, and isolated AI chat windows for literature queries. Copying notes and citations between these tools constantly broke deep focus.

Existing generative AI tools exacerbated this fragmentation. Most conversational interfaces forced complex reasoning into a narrow chat box and generated monolithic text blocks that overwrote existing notes without review gates.

Researchers hesitate to use autonomous agents when destructive edits can erase structured arguments or corrupt citation chains. Furthermore, storing unpublished empirical hypotheses on third-party cloud servers introduced data privacy concerns.

Design Exploration and Discarded Iterations

To resolve this friction, I explored several interaction models before arriving at the final architecture:

Isolated Chat Sidebar

Returning text snippets for manual copy-pasting destroyed spatial layout relationships on the canvas and required constant manual re-formatting of equations and tables.

Autonomous Direct Overwriting

Allowing agents to directly update document blocks triggered immediate user hesitation. Without granular preview controls, even small unexpected changes eroded editorial trust.

Staged Visual Proposals with 3-Pane Sync

Unified an infinite canvas, scholarly document engine, and LangGraph runtime into three synchronized panes. Agents stage additions as non-destructive visual diffs that users inspect and approve with a single click.

Technical Stack

CollarAgent was built as a local-first desktop application engineered around agent orchestration and responsive spatial state management:

  • Desktop Shell and Frontend (Electron, React 19, TypeScript): Cross-platform desktop architecture with Tailwind CSS and Vite, handling multi-window rendering and native file system access.
  • Agent Orchestration Runtime (LangGraph): Multi-agent execution graph with deterministic tool-calling schemas, managing literature extraction, hypothesis graph generation, and staged proposal diffs.
  • Spatial Canvas and State Management: Infinite zoomable vector canvas paired with reactive state management, enabling drag-and-drop linking between visual concept nodes and document sections.
  • Scholarly Document Engine (Lexical and KaTeX): Document editor with instant LaTeX mathematical equation rendering, formatted evidence tables, and native Microsoft Word (.docx) export generation.
  • Local-First Storage and Security: Portable SQLite database storage on local disk with OS keychain credential encryption, atomic checkpoints, and point-in-time state rollbacks.
  • CI/CD and Release Automation: GitHub Actions automated pipelines for type checking, unit tests, and cross-platform desktop release packaging.

Practical Outcomes and Verification

End-to-End Production Validation

CollarAgent served as my daily production workspace to organize dozens of literature sources, map theoretical variables, and draft the complete 8-page research manuscript for IEEE ICVR 2026 before being open sourced.

The unified 3-pane layout eliminated tool switching between whiteboards and word processors. Pairing spatial visual thinking with staged proposal diffs removed destructive overwrite anxiety, allowing rapid exploration of theoretical relationships without losing editorial control or citation integrity.

Lessons Learned and Retrospective

An autonomous research agent should not attempt to be a one-click ghostwriter. Early assumptions favored high-autonomy text generation, but active scholarly writing requires transparent visual boundaries and granular human verification.

The highest-leverage role for AI in research is structured concept extraction and evidence organization, while human researchers retain full editorial ownership through transparent, atomic diff approvals.
