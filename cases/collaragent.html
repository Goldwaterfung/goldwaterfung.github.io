Autonomous Workflows and Interaction Design

CollarAgent: Local-first visual research studio with autonomous agent co-working

Unified an infinite concept canvas, structured document engine, and LangGraph agent runtime with non-destructive diff staging to transform literature exploration into living concept maps and manuscripts.

Role Creator
Project CollarAgent
Timeline 2025
Key Systems Electron, React, TypeScript, LangGraph

Context and Problem

When conducting academic literature reviews and formulating hypotheses, researchers navigate fragmented tools. Thinking happens across whiteboards, note editors, reference managers, and chat windows.

Standard generative AI tools worsen this fragmentation by offering isolated chat boxes or overwriting documents without granular control. Researchers hesitate to let agents edit complex drafts because destructive overwrites destroy nuanced arguments and citations.

System Architecture and User Experience

I designed and built CollarAgent as a local-first Electron desktop application in React + TypeScript that pairs autonomous AI capabilities with direct user manipulation:

  • Infinite Canvas and Document Synchronization: Created bidirectional state synchronization between visual concept nodes and structured document blocks, keeping visual mapping aligned with textual prose.
  • Non-Destructive Visual Diff Staging: Implemented visual proposal staging that allows researchers to inspect, accept, or reject agent edits at the paragraph and node level before applying them to disk.
  • LangGraph Autonomous Workflows: Orchestrated multi-step literature synthesis, hypothesis generation, and evidence extraction agents capable of working alongside the user asynchronously.
  • Persistent Memory Architecture: Designed schema stores that retain user project preferences, style constraints, and verified claims across long-running research sessions.
  • Release Automation: Configured GitHub Actions CI/CD pipelines for type checking, unit testing, and cross-platform desktop release builds.

Practical Outcomes and Verification

End-to-End Validation

CollarAgent served as the daily production workspace used to conduct literature synthesis and draft the complete research manuscript for IEEE ICVR 2026 before being open sourced in August 2026.

The visual diff interface eliminated destructive overwriting anxiety, allowing rapid exploration of dozens of papers without losing editorial ownership. The project confirmed that pairing spatial visual thinking with autonomous agent workflows significantly reduces cognitive fragmentation during complex writing.
